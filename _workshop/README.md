catalogs, reviews, experiments, design proofs, and old briefs. Reference material,
never live tasking (see `docs/ARCHI.md`). Organized by CO-010:

- `design-explorations/` — visual experiments
- `loop/` — the Jun-2026 balance-calibration loop (dormant; see `NOTE.md` before reviving)
- `sandbox/` — scratch experiments
- `briefs/` — program framing, handoffs, review prompts
- `superseded-launchers/` — old launchers, replaced by `▶ Play StrikeSim 2040.command`

Safe to browse, safe to ignore. Deleting anything here never breaks the game — but
`design-proofs/` will be re-filled by the proof tools.
